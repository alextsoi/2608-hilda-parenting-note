# 兒童健康服務 — 首次登記表格

## 資訊圖

![mchc registration](/images/resources/mchc-registration.svg)

圖内文字根據衞生署家庭健康服務網頁整理，**唔構成醫療建議**。

## 適用年齡

首次使用衞生署兒童健康服務時。

## 重點摘要

- 目錄頁提供「兒童健康服務 — 首次登記表格」PDF，**出發前填好**，連同出世紙、針卡、父母身分證明、出院記錄一齊帶。
- 首次登記程序較多，填好表格可慳時間。
- 表格連線同檔案大小以官網當日下載為準。

## 詳細說明

表格由 [共享育兒樂（一）目錄頁](https://www.fhs.gov.hk/tc_chi/health_info/child/30032.html) 下載。帶備文件清單見 [首次到母嬰健康院登記](/resources/../00-0-to-1-month/mchc-first-visit/)。

所有母嬰健康院兒童健康服務以**預約**安排：

- **首次登記**：有黃疸或母乳餵哺問題要盡早約。可於兒童健康服務時段親身到選定健康院，或致電預約。
- **舊症**：帶針卡到院預約、致電讀出健康院編號（針卡編號）、或用網上預約系統更改／取消／翻查。

## 注意事項

請在指定**登記時間**內到達，否則可能未能安排當日服務。部分健康院只喺每周指定日子開放。
