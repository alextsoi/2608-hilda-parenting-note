# 坐月餐單參考（P 牌媽媽）

整理自公開坐月餐單分享，方便 P 牌媽媽同照顧者**揀菜式、配食材**，唔係逐日固定菜單。現代月子餐可以日日唔同，重點係配搭得當、煮得方便。

**唔構成醫療或營養建議**。食材是否適合你，請向母嬰健康院、註冊中醫或醫護查詢；哺乳相關見 [哺乳媽媽的營養](/mother/breastfeeding-nutrition/)。

---

## 適用對象

產後坐月、自己安排餐單嘅媽媽同照顧者（包括 P 牌爸爸一齊睇，方便分工備料）。

## 重點摘要

- **少油、少鹽、少糖**；**少食多餐**；**多飲湯水**，有利恢復同乳汁分泌。
- 坐月唔等於「冇啖好食」——下面係**參考清單**，可輪流配搭，唔使跟足每一項。
- 睇菜單前，先了解常見**有益食材／藥材**（見下表），再按類別揀早餐、正餐、湯水、甜品。
- 有**不宜食物**清單；唔肯定某樣食材食唔食得，先問註冊中醫或醫生。
- **母乳媽媽注意**：花膠可能引致塞奶（不宜多食）；北芪杞子燉乳鴿——母乳餵哺者不宜。

## 詳細說明

### 坐月常見有益食材／藥材

| 食材／藥材 | 常見用途（民間說法） |
| --- | --- |
| 杜仲 | 紓緩腰膝痠痛 |
| 桑寄生 | 紓緩關節痠痛 |
| 茯苓 | 改善水腫、代謝 |
| 黑芝麻 | 促進乳汁分泌（母乳媽媽） |
| 杞子 | 改善氣血不足、視力模糊 |
| 陳皮 | 改善胃口 |
| 百合 | 改善睡眠 |
| 南棗 | 改善自汗、盜汗 |
| 海參 | 改善小便頻密 |
| 淮山 | 促進傷口愈合 |

以上係民間／傳統說法摘要；詳細功效可再查閱可靠來源或問註冊中醫。

### 早餐參考

紅糖粥 · 桂圓粥 · 五更飯 · 花膠紅米粥* · 南瓜肉絲通粉 · 瑤柱花生魚片粥 · 薑片南瓜粥 · 冬菇紅棗魚片粥 · 紅棗桂圓雞粥 · 花生紅棗肉粥 · 蠔鼓豬潤粥

\* **花膠紅米粥**：母乳媽媽注意，花膠有機會引致塞奶，不宜多食。

**約坐月一個月後**，可慢慢加返：三文治、麵包、麥皮、粟米片。
