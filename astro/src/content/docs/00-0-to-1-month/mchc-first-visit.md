# 首次到母嬰健康院登記所須帶備文件

## 資訊圖

![mchc first visit](/images/00-0-to-1-month/mchc-first-visit.svg)

圖内文字根據衞生署家庭健康服務網頁整理，**唔構成醫療建議**。

## 適用年齡

初生（出院後盡早預約）。

## 重點摘要

出院後盡早致電母嬰健康院或私營機構預約兒童健康服務。首次登記時間較長：登記、量體重、檢驗黃疸、護士接見，個別情況即時身體檢查。建議媽媽陪同，預留時間餵母乳，帶尿片；奶粉餵哺就帶調奶用品。可請親友陪同。

## 詳細說明

### 要帶咩

1. 免疫接種記錄（針卡）
2. 出生證明文件（出世紙）；非本港出生帶有效旅行證件
3. 父母有效香港身份證（副本可）；沒有就帶有效旅行證件（副本可）
4. 初生嬰兒出院記錄（血液報告、聽力測試等）
5. 母親健康院產前登記卡（如適用；亦可帶產前醫療記錄）
6. 已填妥「兒童健康服務 — 首次登記表格」

要帶有效身分證明核實。若未能提交嬰兒有效香港出生證明，健康院可按非符合資格人士現行收費收費。辦理出世紙見入境事務處網頁。

### 當日提示

- 媽媽陪同，方便隨時餵母乳。
- 帶尿片等初生物品。
- 發燒、出疹（紅疹、水疱）、最近患傳染病或接觸患者：**唔好進入**母嬰健康院；改去家庭醫學診所或私家診所，並致電改期。
- 預約日前若擔心健康（尤其周末或假期），可先去私家醫生或急症室。
